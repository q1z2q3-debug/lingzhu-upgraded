## 📊 增长指标追踪

### 社区指标
- GitHub Stars
- Fork 数
- 贡献者数量
- Issue 解决率
- Discord/微信群成员

### 产品指标
- API 调用量
- 活跃用户数 (DAU/MAU)
- 平均会话时长
- 功能使用率
- NPS (净推荐值)

### 商业指标
- 付费用户数
- MRR (月经常性收入)
- Churn Rate (流失率)
- CAC (获客成本)
- LTV (生命周期价值)

---

## 🔄 迭代原则

1. **双周迭代** — 每两周发布一个小版本
2. **季度大版本** — 每季度一个里程碑版本
3. **社区驱动** — Issue 和 PR 决定优先级
4. **数据决策** — 用指标指导产品方向
5. **透明运营** — 公开路线图和进展
