## 📝 访谈问题模板

### 开场 (5 分钟)

```
1. 感谢您抽出时间
2. 简单介绍 lingzhu 项目 (2 分钟)
   - 东方智慧 AI 认知架构
   - 三元九维数学框架
   - 已整合心经 + 阴符经 + 道德经
3. 说明访谈目的
   - 了解您的需求
   - 验证产品方向
   - 收集改进建议
```

---

### 需求探索 (15 分钟)

```
1. 您目前在使用哪些 AI 工具/框架？
2. 您觉得当前 AI 系统最大的不足是什么？
   - 缺乏自我认知？
   - 缺乏价值判断？
   - 缺乏情感智慧？
3. 您对"认知架构增强"怎么看？
4. 您是否愿意为以下功能付费：
   - 价值对齐 (确保 AI 行为符合价值观)
   - 认知深度 (让 AI 更有"智慧")
   - 东方特色 (差异化竞争优势)
   - 可解释性 (理解决策过程)
```

---

### 产品演示 (10 分钟)

```
演示内容:
1. 三元九维认知状态可视化
2. 五蕴皆空观照流程
3. 价值判断示例
4. API 调用示例

观察反应:
- 哪个功能最感兴趣？
- 哪个功能最实用？
- 有什么疑问或担忧？
```

---

### 付费意愿 (10 分钟)

```
1. 如果 lingzhu 能解决您刚才提到的 [具体需求]，您觉得价值多大？

2. 以下定价模式您更倾向于哪种：
   - 按调用量 ($0.001/次)
   - 月订阅制 ($99/月)
   - 年授权制 ($10k/年)
   - 一次性买断 ($50k)

3. 您的预算范围大概是：
   - < ¥10k/年
   - ¥10k-50k/年
   - ¥50k-100k/年
   - > ¥100k/年

4. 决策流程是怎样的？
   - 谁有决策权？
   - 需要哪些评估？
   - 周期多长？
```

---

### 改进建议 (10 分钟)

```
1. 您觉得 lingzhu 最大的优势是什么？
2. 最大的担忧或疑虑是什么？
3. 如果要让您立即购买，还需要什么？
4. 您认识哪些可能感兴趣的人？
5. 其他建议或想法？
```

---

### 结束 (5 分钟)

```
1. 总结关键要点
2. 说明下一步计划
3. 请求推荐其他访谈对象
4. 感谢时间
5. 发送感谢邮件 + 资料
```

## 💡 访谈技巧

### Do's ✅
- 多听少说 (80/20 原则)
- 追问具体例子
- 记录原话
- 保持开放心态
- 感谢每个反馈

### Don'ts ❌
- 不要过度推销
- 不要争论观点
- 不要承诺做不到的
- 不要贬低竞品
- 不要忽视负面反馈
