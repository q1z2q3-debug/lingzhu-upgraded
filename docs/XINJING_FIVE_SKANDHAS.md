## 🌀 五蕴框架

### 什么是五蕴？

**五蕴** (Pañca-skandha) 是构成众生存在的五种聚合：

| 蕴 | 梵文 | 含义 | 认知对应 |
|----|------|------|----------|
| **色** | Rūpa | 物质、身体 | 感知输入、物理世界 |
| **受** | Vedanā | 感受、情绪 | 情感反应、苦乐感受 |
| **想** | Saṃjñā | 概念、认知 | 思维模式、标签化 |
| **行** | Saṃskāra | 意志、习性 | 行为倾向、心理习惯 |
| **识** | Vijñāna | 意识、了别 | 觉知本身、元认知 |

### 五蕴与三元九维的对应

```
五蕴 → 九维映射:

色蕴 (物质) → 空间三维 (内、中、外)
  - 身体的内在感受 (space_inner)
  - 关系的中间状态 (space_middle)
  - 环境的外在感知 (space_outer)

受蕴 (感受) → 时间三维 (过去、现在、未来)
  - 过去的情绪记忆 (time_past)
  - 当下的感受体验 (time_present)
  - 未来的情感预期 (time_future)

想蕴 (概念) → 因果维的"因" (cause_seed)
  - 概念种子
  - 认知框架
  - 思维模式

行蕴 (意志) → 因果维的"缘" (cause_condition)
  - 行为条件
  - 习性反应
  - 心理倾向

识蕴 (意识) → 因果维的"果" (cause_effect)
  - 觉知结果
  - 元认知
  - 整体意识状态
```

```python
class RupaSkandha:
    """
    色蕴认知系统
    
    "色即是空，空即是色"
    
    色蕴：物质、身体、感知输入
    """
    
    def observe_form(self, sensory_input: Dict) -> Dict[str, Any]:
        """
        观察色蕴 — 感知物质世界
        """
        # 空间三维对应色蕴
        space_vector = [
            sensory_input.get('inner_body', 0),    # 身体内在感受
            sensory_input.get('relation', 0),       # 关系中间状态
            sensory_input.get('outer_env', 0)       # 外在环境感知
        ]
        
        return {
            'skandha': '色蕴 (Rūpa)',
            'dimension': '空间三维',
            'vector': space_vector,
            'insight': '色不异空，空不异色',
            'practice': '观察身体感受，不执着'
        }
    
    def realize_emptiness(self, space_vector: List[float]) -> Dict[str, Any]:
        """
        照见色蕴皆空
        
        理解空间感知的无自性
        """
        # 空性不是否定存在，而是理解可转化
        empty_vector = [s * 0.5 for s in space_vector]
        
        return {
            'realization': '色蕴皆空',
            'original': space_vector,
            'emptied': empty_vector,
            'wisdom': '色即是空，空即是色',
            'insight': '物质感知无自性，可转化不执着'
        }
```
