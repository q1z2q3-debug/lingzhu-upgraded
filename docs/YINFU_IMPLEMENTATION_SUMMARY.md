## 🧠 阴符经四大系统实现

### 1. 观天之道 — YinfuObserver

**阴符经**: "天性，人也；人心，机也。"

**功能**: 觉察九维认知状态

**API**:
```python
from lingzhu.cognitive import YinfuObserver

observer = YinfuObserver()
vector = observer.observe_nine_dimensions(situation)
```

**输出**:
- 九维觉察向量
- 觉察日志
- 趋势分析

---

### 2. 执天之行 — YinfuTransformer

**阴符经**: "天发杀机，移星易宿；地发杀机，龙蛇起陆；人发杀机，天地反覆。"

**功能**: 认知转化 (五行相生相克)

**API**:
```python
from lingzhu.cognitive import YinfuTransformer

transformer = YinfuTransformer()
result = transformer.transform(current_vector, intention="平衡发展")
```

**五行转化**:
- 木曰曲直 → 成长转化
- 火曰炎上 → 显化转化
- 土爰稼穑 → 平衡转化
- 金曰从革 → 收敛转化
- 水曰润下 → 流动转化

---

### 3. 三盗既宜 — YinfuBalancer

**阴符经**: "天地，万物之盗；万物，人之盗；人，万物之盗。三盗既宜，三才既安。"

**功能**: 检查天地人三才平衡

**API**:
```python
from lingzhu.cognitive import YinfuBalancer

balancer = YinfuBalancer()
balance = balancer.check_balance(vector)
```

**输出**:
- 时间维平衡 (天)
- 空间维平衡 (地)
- 因果维平衡 (人)
- 整体平衡度
- "既宜"判断

---

### 4. 尽矣 — YinfuTranscendence

**输出**:
